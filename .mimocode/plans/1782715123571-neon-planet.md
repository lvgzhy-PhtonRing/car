# 预期价格联动系统设计方案

## 一、现状分析

### 当前实现
- 每辆车独立存储 `expectedValue` 和 `expectedHistory`
- 估价系统（预期价格更新器）实现了同名联动（第3181-3190行）
- 买小车和编辑小车只有"预读取"功能（`autoFillExpected`），没有联动更新
- `appendExpectedHistory` 函数只更新单辆车

### 用户需求
1. 同名称小车预期价格联动，跨库联动（自留库和投资库）
2. 买小车、编辑小车、估价系统均预读取这个价格
3. 当用户新填入数值时，提示会造成全库本型号预期价格联动

### 2.2 核心函数

#### 读取函数
```javascript
// 获取同款车的预期价格（从中央索引或现有车辆中取最高值）
function getExpectedPrice(brand, name) {
  if (!brand || !name) return 0;
  const key = brand + '|' + name;
  
  // 优先从中央索引读取
  if (carAppData.expectedPrices && carAppData.expectedPrices[key]) {
    return carAppData.expectedPrices[key].value;
  }
  
  // 降级：从现有车辆中取最高值
  return getMaxExpectedForSameCar(brand, name);
}
```

#### 写入函数
```javascript
// 设置同款车的预期价格（联动所有同名车）
function setExpectedPrice(brand, name, value, date) {
  if (!brand || !name || !value) return;
  const key = brand + '|' + name;
  const today = date || getToday();
  
  // 初始化中央索引
  if (!carAppData.expectedPrices) carAppData.expectedPrices = {};
  
  // 更新中央索引
  if (!carAppData.expectedPrices[key]) {
    carAppData.expectedPrices[key] = { value: 0, date: today, history: [] };
  }
  const entry = carAppData.expectedPrices[key];
  entry.value = value;
  entry.date = today;
  entry.history.unshift({ date: today, value: value });
  
  // 联动更新所有同名未售出车辆（跨库）
  carAppData.cars.forEach(car => {
    if (car.brand === brand && car.name === name && !car.isSold) {
      car.expectedValue = value;
      if (!car.expectedHistory) car.expectedHistory = [];
      car.expectedHistory.unshift({ date: today, value: value });
    }
  });
  
  return getAffectedCarsCount(brand, name);
}

// 获取受影响的车辆数量
function getAffectedCarsCount(brand, name) {
  return carAppData.cars.filter(c => 
    c.brand === brand && c.name === name && !c.isSold
  ).length;
}
```

### 2.3 修改点

#### 2.3.1 数据迁移（loadData 后）
```javascript
// 在 loadData() 中添加迁移逻辑
function migrateExpectedPrices() {
  if (!carAppData.expectedPrices) carAppData.expectedPrices = {};
  
  // 从现有车辆中构建中央索引
  carAppData.cars.forEach(car => {
    if (car.isSold || !car.brand || !car.name) return;
    const key = car.brand + '|' + car.name;
    const expected = car.expectedValue || car.buyPrice || 0;
    
    if (!carAppData.expectedPrices[key]) {
      carAppData.expectedPrices[key] = { value: expected, date: car.buyDate || getToday(), history: [] };
    } else if (expected > carAppData.expectedPrices[key].value) {
      // 取最高值
      carAppData.expectedPrices[key].value = expected;
    }
  });
}
```

### 2.4 提示机制

```javascript
// 预期价格变化时的联动提示
function onExpectedChange(brandFieldId, nameFieldId, expectedFieldId) {
  const brand = document.getElementById(brandFieldId)?.value || '';
  const name = document.getElementById(nameFieldId)?.value || '';
  const expected = parseFloat(document.getElementById(expectedFieldId)?.value) || 0;
  
  const hintEl = document.getElementById('expectedSyncHint');
  const countEl = document.getElementById('affectedCount');
  
  if (!brand || !name || !expected || !hintEl || !countEl) {
    if (hintEl) hintEl.classList.add('hidden');
    return;
  }
  
  const count = getAffectedCarsCount(brand, name);
  if (count > 0) {
    countEl.textContent = count;
    hintEl.classList.remove('hidden');
  } else {
    hintEl.classList.add('hidden');
  }
}
```

## 五、技术要点

1. **向后兼容**：保持 `expectedHistory` 结构不变，确保历史数据不丢失
2. **性能优化**：中央索引避免每次遍历所有车辆
3. **用户体验**：联动提示清晰，让用户知道修改会影响多少辆车
4. **数据一致性**：所有写入点统一调用 `setExpectedPrice`，确保数据一致
